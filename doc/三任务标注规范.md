# 三任务标注规范

> 日期：2026-11-11
> 适用卷：`data/dataset/` 下的 `ner_*`、`ee_*`、`re_*`，由 [dataset/build.py](../dataset/build.py) 生成
> 标注工具：`python3 -m annotate.tasks`

## 一、总体约定

三个任务共享同一批文本，各自独立标注与评测。一篇稿件可以在三个卷里各出现一次，三次判定互不依赖。

| 任务 | 标什么 | 不标什么 |
| --- | --- | --- |
| NER | 五类实体的片段与类型 | 事件、关系 |
| EE | 原子事件与六类论元、复合事件与包含关系 | 实体间的结构关系 |
| RE | 实体间的十种结构关系 | 事件、论元 |

**统一要求**：所有取值必须是原文中的连续子串，逐字复制，不改写、不顺句、不补全。

## 二、NER 卷

### 2.1 五类实体

| 类型 | 收 | 不收 |
| --- | --- | --- |
| 机构 | 政府、军队、部门、国际组织、国家；带机关后缀的称谓（总统府、总统办公室、国防部、联合国秘书处） | 职务串（「美国总统」「国防部长」「俄军总参谋长」「联合国秘书长」）；职务描述式名称（「一名发言人」「该官员」） |
| 人物 | 有姓名的自然人；职务后紧跟姓名时只留姓名 | 记者、通讯员、消息人士、分析人士、观察员；纯职务串（「美国总统」「乌克兰总统」） |
| 装备 | 武器、系统、舰船、飞机。有型号时取其原文写法（「F-35 战斗机」「F-16」） | 全篇已有型号时的纯通称（「无人机」「导弹」「航母」） |
| 地点 | 地名、海域、基地 | 机构驻地以外的场所描述 |
| 作品 | 有正式题名的协议、条约、法案、报告、影像；带文书后缀的称谓（总统令、总统法） | 无题名的口头承诺、泛指的「协议」 |

**职务串不进实体表。** 职务、官衔只是称谓，不是实体。「美国总统」「乌克兰总统」「俄军总参谋长」「国防部长」「联合国秘书长」「俄总统新闻秘书」「伊朗军方发言人」都不标。看后缀区分三种情况：跟「府、办公室、部、局、院、委员会、司令部、秘书处」的是机构；跟「令、法、案、条例」的是作品；其余是称谓。

**只留姓名。** 原文写「美国总统特朗普」时，标「特朗普」（人物），不标「美国总统」；职务写进人物属性的「身份/职业」。「法国总统马克龙」只留「马克龙」，同理。

**同名只列一次。** 同一实体在一篇里出现多次，只在候选里列一条，标注一次即可。图谱按文档建节点，同名视为同一主体，不需要逐处标注。若要标明某处指代有歧义，写在备注里。

**装备看型号。** 装备的取名规则分三种，关键是实体必须是原文里连续的一段，不能补字。

| 原文写法 | 实体名 | 说明 |
| --- | --- | --- |
| 「F-35 战斗机」 | 「F-35 战斗机」 | 型号带通名时取完整片段 |
| 「A-10 攻击机」 | 「A-10 攻击机」 | 同上 |
| 「S-400 系统」 | 「S-400 系统」 | 同上 |
| 「乌军 F-16 已交付」 | 「F-16」 | 只有型号时只取型号，不补通名 |
| 「俄军使用无人机袭击」且全篇无型号 | 「无人机」 | 全篇无型号才抽通名 |

带型号的候选在界面上有「型号」标记，便于核对写法是否与原文一致。

全篇已有型号时，不要用「无人机」「导弹」代替具体型号。这类漏抽会让装备实体只剩通称，丢失关键信息。

### 2.2 判定动作

对每条候选做三选一：

- **保留**：片段与类型都对
- **修改**：片段对但类型错，改成正确类型
- **删除**：片段对不上原文、是代词、是该丢的角色名

另需**补充**模型漏掉的实体。漏抽的判定标准：原文中出现、属于五类、且不是代词。

### 2.3 边界

**国家与军队分开。** 「美国」是机构，「美军」是另一个机构，不合。

**机构与地点分开。** 「五角大楼」是机构，「华盛顿」是地点。

**职务与机关分开。** 「美国总统」是称谓（不标），「美国政府」「白宫」「总统办公室」是机构。「俄军总参谋长」是称谓（不标），「俄军总参谋部」是机构。判断依据只有一个：职务词后面有没有机关后缀。

**职务与人名合一。** 「美国总统特朗普」标一个实体「特朗普」，type 为人物；不要额外标「美国总统」。原文只写职务没写名字时（如「乌克兰总统表示」），也不标职务串——这条信息留在关系证据里，不产生实体。

**装备与泛称。** 原文写「F-16 战斗机」就收具体型号；写「战机」且全篇无型号时收「战机」。

## 三、EE 卷

### 3.1 事件判定

原子事件必须同时满足：

- 有明确施动者，且施动者能在实体表里找到
- 是单个主谓结构，不含目的从句、结果从句
- 长度 8 至 90 字
- 不含条件句标记（如果、若、假如、一旦）
- 文本自带施动者，不靠关系补

反例：

- 「造成 3 名军人受伤」——无施动者
- 「提升作战能力」——目的从句
- 「导致机场运行受影响」——结果从句
- 「如果美以发动打击」——条件句
- 「强行部署远程导弹」——施动者缺失，应写「日本强行部署远程导弹」

### 3.2 事件类型

事件有两个类型标签：先判一级（性质），再判二级（动作）。二级必须属于所判的一级。

**一级：行为性质**

| 一级 | 判据 |
| --- | --- |
| 对抗 | 双方或多方发生武力冲突、控制争夺、强制拘押。有明确的敌对方，或单方施加武力 |
| 部署 | 己方兵力的移动、集结、演练、撤收，无直接交火 |
| 合作 | 多方参与，指向共识或互助 |
| 表态 | 只有说，没有做。转述、声明、发布信息都归这里 |
| 其他 | 事故、立法、人事、调查等不属于上述四类的 |

**二级：具体动作**

| 一级 | 二级 | 判据 |
| --- | --- | --- |
| 对抗 | 打击 | 袭击、攻击、突击、交火、作战、造成伤亡 |
| 对抗 | 空袭 | 用航空器投弹或扫射 |
| 对抗 | 拦截 | 击落、击毁、防空作战 |
| 对抗 | 发射 | 发射、试射 |
| 对抗 | 控制 | 占领、攻占、接管、封锁、包围、拘押 |
| 部署 | 投送 | 增派、派遣、进驻、集结、组建、布防 |
| 部署 | 机动 | 推进、开进、调动、转场、起飞、巡航 |
| 部署 | 战备 | 进入战备等级、动员、戒备、警巡 |
| 部署 | 演习 | 演练、训练、联演、试射 |
| 部署 | 撤离 | 撤出、撤退、返航 |
| 合作 | 签署 | 签署、缔结、达成协议、加入、退出、批准 |
| 合作 | 谈判 | 谈判、和谈、磋商、对话、斡旋 |
| 合作 | 会议 | 会议、峰会、论坛、例会、仪式、庆典 |
| 合作 | 访问 | 访问、出访、到访、接见、视察 |
| 合作 | 援助 | 军援、支援、救济、提供物资或资金 |
| 表态 | 声明 | 一般性陈述、通告、发布信息 |
| 表态 | 呼吁 | 要求、敦促、倡议 |
| 表态 | 警告 | 威胁、划红线、预告后果 |
| 表态 | 否认 | 驳斥、拒绝承认 |
| 表态 | 承认 | 证实、确认、供认 |
| 表态 | 谴责 | 批评、抗议、抨击 |

其他类不分二级，留空。判不出二级时也留空，不要硬套。

### 3.3 边界判定

**空袭与打击。** 空袭必须用航空器。地面炮击、导弹袭击归打击。

**打击与拦截。** 击落来袭目标归拦截；打击对方阵地归打击。

**签署与谈判。** 签署是已达成的结果；谈判是正在进行的交涉。

**谈判与会议。** 谈判是双方为达成协议的交涉；会议是多边或正式集会，含峰会、例会、仪式。

**访问与部署。** 访问是人员往来；部署是军事力量调动。「视察」归访问，「调动部队」归部署。

**表态与实施。** 只宣布而未执行的是表态；已经执行的是对应的一级。
例：「宣布组建新司令部」归表态·声明；「新司令部已组建完成」归部署·部署。

**表态的二级。** 判定依据是言语行为本身的性质，不看被转述的内容。
转述句里出现的空袭、部署属于被转述方，本次事件仍是表态，二级按说话人的言语性质定。

### 3.4 时序

| kind | 判据 |
| --- | --- |
| 发生 | 已发生或正在发生 |
| 表态 | 口头口径：称、表示、谴责、警告、否认、演讲、发布会 |
| 计划 | 将、拟、考虑、讨论、准备，尚未发生 |

判定顺序：先看是否为转述（出现「称/表示/声明」且标记前有主体）→ 表态；再看计划标记有无完成标记 → 计划；规范句（必须、应当）→ 表态；其余 → 发生。

时态优先于言语动词：「已制定方案」判发生，不因含「制定」判计划。

### 3.5 六类论元

| 论元 | 含义 | 反例 |
| --- | --- | --- |
| 施事 | 发起或执行该事件 | 「出席会谈」不是施事 |
| 受事 | 被打击、被控制、被波及 | 「旁观」不是受事 |
| 到场 | 出席、参加，但不是施事 | 「主持会议」是施事不是到场 |
| 使用 | 事件中动用的装备 | 装备被摧毁不是使用 |
| 涉及 | 事件关联的文书 | 口头承诺不是作品 |
| 表态 | 谁就此事表态，带 stance 枚举 | 转述第三方观点不算本人的表态 |

表态的 stance 取值：支持、反对、谴责、警告、否认、承认、呼吁、要求、关切、中立。原文没有明确态度词时不建这条边。

### 3.6 复合事件

复合事件是对同篇多个原子事件的概括，10 至 40 字，至少覆盖 2 个原子事件。

判定要点：

- 是概括而非重述其中一个原子事件
- 覆盖的原子事件编号必须正确
- 原子事件不足 2 个时由标题兜底生成，标 `fallback=true`

## 四、RE 卷

### 4.1 十种结构关系

| 关系 | 方向 | 判据 | 正例 |
| --- | --- | --- | --- |
| 隶属 | 机构 → 机构 | 上级机关 | 五角大楼 —隶属→ 美国国防部 |
| 辖属 | 机构 → 机构 | 国别归属，终点是国家 | 韩国国防部 —辖属→ 韩国 |
| 驻地 | 机构 → 地点 | 常驻位置 | 美军中央司令部 —驻地→ 卡塔尔 |
| 部署方 | 装备 → 机构 | 装备由谁部署 | 爱国者系统 —部署方→ 美军 |
| 去向 | 装备 → 地点 | 装备实际移动到某地 | 林肯号 —去向→ 中东 |
| 任职 | 人物 → 机构 | 原文写明职务与机构的对应 | 赫格塞思 —任职→ 美国国防部 |
| 会晤 | 人物 → 人物 | 面对面或通话 | 特朗普 —会晤→ 塞西 |
| 搭载 | 装备 → 装备 | 载体与载荷 | 台风战机 —搭载→ 流星导弹 |
| 位于 | 地点 → 地点 | 行政或地理包含 | 塔伊兹省 —位于→ 也门 |
| 敌对 | 机构 → 机构 | 交火、宣战、明确对抗 | 以军 —敌对→ 哈马斯 |

### 4.2 边界

**任职与隶属。** 任职两端是人物与机构；隶属两端都是机构。「曾在该机构工作」不算任职，必须有明确职务。

**会晤与到场。** 会晤是人物之间的稳定关系，不依赖单次事件；「出席某会议」是事件的到场论元，不进 RE。

**搭载与使用。** 搭载是装备之间的装载关系；「事件使用某装备」是事件的论元。

**位于与驻地。** 位于两端都是地点，是行政或地理关系；部队在某地是驻地。

**敌对与表态。** 敌对要求有具体的对抗事实（交火、宣战）；仅有口头交锋归表态的 stance。

### 4.3 判定动作

对每条候选三元组做四选一：

- **保留**：两端与关系都对
- **改关系**：两端对但关系错，改成正确关系
- **改端点**：关系对但某一端片段错，改成正确片段
- **删除**：原文不支持该关系

另需补充模型漏掉的三元组。只在原文明确写出关系时补，不做推理。

## 五、质量要求

### 5.1 双人独立标注

开发卷与测试卷全部双标，标注员互不通气。

### 5.2 一致性门槛

| 任务 | 指标 | 门槛 |
| --- | --- | ---: |
| NER | 实体片段与类型的 Cohen κ | ≥ 0.75 |
| EE | 事件边界 κ | ≥ 0.65 |
| EE | 事件类型 κ | ≥ 0.75 |
| EE | 话语种类 κ | ≥ 0.75 |
| EE | 论元角色 κ | ≥ 0.70 |
| RE | 三元组 κ | ≥ 0.70 |

事件边界门槛设得低一些，因为涉及片段切分，天然分歧大。

### 5.3 仲裁

两人不一致的交第三人。同一类争议在试点卷累计超过 5 例时，修订本规范并回溯已标部分。

### 5.4 冻结

测试卷标注完成并仲裁后冻结，冻结时记录规范版本号。冻结后不再修改。

## 六、评测指标

### 6.1 NER

微平均 P/R/F1。一条预测正确须片段起止与类型同时匹配。五类各报一个，另报合计。

### 6.2 EE

沿用 CMNEE 口径：

- **Trg-F1**：trigger 片段与事件类型同时正确
- **Arg-F1**：论元角色与片段同时正确

复合事件单独报 F1，`包含` 边的覆盖率作为辅助指标。

### 6.3 RE

三元组全匹配，与 DuIE 一致。只统计有结构关系的实体对，负例按 1:3 采样。

### 6.4 三任务不合并

三个指标分开报，不合成单一总分。实体 F1 不含事件，事件指标不含实体，关系指标不含论元。

## 七、已知限制

**RE 卷规模偏小。** 现有语料以事件报道为主，人物履历与装备编成类信息少。100 篇里只有 29 篇有结构关系，52 条三元组。扩大 RE 卷需要专门筛选含任职、会晤、敌对、搭载、位于语义的稿件，或引入外部语料。

**新增五种关系样本稀少。** 在 100 篇上试抽，任职 7 条、敌对 5 条、位于 5 条，会晤与搭载未出现。评测时需按关系种类分别报，不只看总体。

**零事件篇。** 约 9% 的稿件抽不出原子事件，只能靠复合事件兜底。这类篇目在 EE 卷里仍有复合事件可标，不算空卷。
