# 三任务标注规范

> 日期：2026-11-11
> 适用卷：`data/dataset/` 下的 `ner_*`、`ee_*`、`re_*`，由 [dataset/build.py](../dataset/build.py) 生成
> 标注工具：`python3 -m annotate.tasks`

## 一、总体约定

三个任务共享同一批文本，各自独立标注与评测。一篇稿件可以在三个卷里各出现一次，三次判定互不依赖。

| 任务 | 标什么 | 不标什么 |
| --- | --- | --- |
| NER | 五类实体的片段与类型 | 事件、关系 |
| EE | 原子事件与六类论元、复合事件与包含关系 | 实体间的结构关系 |
| RE | 实体间的十种结构关系 | 事件、论元 |

**统一要求**：所有取值必须是原文中的连续子串，逐字复制，不改写、不顺句、不补全。

## 二、NER 卷

### 2.1 五类实体

| 类型 | 收 | 不收 |
| --- | --- | --- |
| 机构 | 政府、军队、部门、国际组织、国家；带机关后缀的称谓（总统府、总统办公室、国防部、联合国秘书处） | 职务串（「美国总统」「国防部长」「俄军总参谋长」「联合国秘书长」）；职务描述式名称（「一名发言人」「该官员」） |
| 人物 | 有姓名的公开身份；单独出现的职务串（「乌克兰总统」指代泽连斯基时按人物） | 记者、通讯员、消息人士、分析人士、观察员 |
| 装备 | 武器、系统、舰船、飞机 | 泛称（「无人机」「导弹」）在原文有具体型号时 |
| 地点 | 地名、海域、基地 | 机构驻地以外的场所描述 |
| 作品 | 有正式题名的协议、条约、法案、报告、影像；带文书后缀的称谓（总统令、总统法） | 无题名的口头承诺、泛指的「协议」 |

**职务串一律按人物。** 「美国总统」「乌克兰总统」「以色列总理」「俄军总参谋长」「国防部长」「联合国秘书长」「俄总统新闻秘书」都是人，不是机关。区分办法看后缀：职务词后面直接结束、或只跟一个人名，就是人物；跟了「府、办公室、部、局、院、委员会、司令部、秘书处」这类机关后缀，才是机构。跟了「令、法、案、条例」这类文书后缀，是作品。

**一人一实体。** 原文写「美国总统特朗普」时，规范实体是「特朗普」（人物），不要把「美国总统」另立一个节点；职务信息写进人物属性的「身份/职业」。同理「法国总统马克龙」只留「马克龙」。

### 2.2 判定动作

对每条候选做三选一：

- **保留**：片段与类型都对
- **修改**：片段对但类型错，改成正确类型
- **删除**：片段对不上原文、是代词、是该丢的角色名

另需**补充**模型漏掉的实体。漏抽的判定标准：原文中出现、属于五类、且不是代词。

### 2.3 边界

**国家与军队分开。** 「美国」是机构，「美军」是另一个机构，不合。

**机构与地点分开。** 「五角大楼」是机构，「华盛顿」是地点。

**职务与机关分开。** 「美国总统」是人物，「美国政府」「白宫」「总统办公室」是机构。「俄军总参谋长」是人物，「俄军总参谋部」是机构。判断依据只有一个：职务词后面有没有机关后缀。

**职务与人名合一。** 「美国总统特朗普」标一个实体「特朗普」，type 为人物；不要额外标「美国总统」。人名缺失时才单独标职务串（如「乌克兰总统表示」里只有「乌克兰总统」，标人物）。

**装备与泛称。** 原文写「F-16 战斗机」就收具体型号；写「战机」且全篇无型号时收「战机」。

## 三、EE 卷

### 3.1 事件判定

原子事件必须同时满足：

- 有明确施动者，且施动者能在实体表里找到
- 是单个主谓结构，不含目的从句、结果从句
- 长度 8 至 60 字
- 不含条件句标记（如果、若、假如、一旦）
- 文本自带施动者，不靠关系补

反例：

- 「造成 3 名军人受伤」——无施动者
- 「提升作战能力」——目的从句
- 「导致机场运行受影响」——结果从句
- 「如果美以发动打击」——条件句
- 「强行部署远程导弹」——施动者缺失，应写「日本强行部署远程导弹」

### 3.2 事件类型

| 类型 | 判据 |
| --- | --- |
| 空袭 | 用航空器投弹或扫射 |
| 打击 | 袭击、攻击、突击、交火、作战、政变、造成伤亡 |
| 拦截 | 击落、击毁、防空作战 |
| 发射 | 发射、试射 |
| 部署 | 部署、增派、调动、进驻、起飞、巡航、交付、移交、组建、调整编制 |
| 撤离 | 撤出、撤退、返航 |
| 演习 | 演练、训练、实弹测试、联演、军事考察 |
| 控制 | 占领、攻占、接管、封锁、包围、隔离、宵禁 |
| 签署 | 签署、缔结、达成协议或共识、加入、退出、批准 |
| 谈判 | 谈判、和谈、磋商、对话、会谈、会晤、斡旋 |
| 会议 | 会议、峰会、论坛、例会、仪式、庆典、选举、任命、集会抗议 |
| 访问 | 访问、出访、到访、抵达、接见、视察 |
| 逮捕 | 逮捕、拘押、起诉、审判、判决 |
| 援助 | 军援、支援、救济、提供物资或资金 |
| 声明 | 声明、表示、称、谴责、警告、否认、呼吁、演讲、发布会 |
| 其他 | 以上都不适用，须在备注写明理由 |

### 3.3 边界判定

**空袭与打击。** 空袭必须用航空器。地面炮击、导弹袭击归打击。

**打击与拦截。** 击落来袭目标归拦截；打击对方阵地归打击。

**签署与谈判。** 签署是已达成的结果；谈判是正在进行的交涉。

**谈判与会议。** 谈判是双方为达成协议的交涉；会议是多边或正式集会，含峰会、例会、仪式。

**访问与部署。** 访问是人员往来；部署是军事力量调动。「视察」归访问，「调动部队」归部署。

**表态优先。** 事件的 kind 为表态时，事件类型一律填声明。转述内容里出现的空袭、部署等动作属于被转述方，不算本次事件的动作类型。

### 3.4 话语种类

| kind | 判据 |
| --- | --- |
| 发生 | 已发生或正在发生 |
| 表态 | 口头口径：称、表示、谴责、警告、否认、演讲、发布会 |
| 计划 | 将、拟、考虑、讨论、准备，尚未发生 |

判定顺序：先看是否为转述（出现「称/表示/声明」且标记前有主体）→ 表态；再看计划标记有无完成标记 → 计划；规范句（必须、应当）→ 表态；其余 → 发生。

时态优先于言语动词：「已制定方案」判发生，不因含「制定」判计划。

### 3.5 场景

场景是事件发生的场合形式，与事件类型正交。取值：战斗、演习、访问、会谈、记者会、视察、会议、谈判、审判、选举、签署、部署、巡逻、救援、其他。

判据：看场合不看内容。「在记者会上宣布空袭」的事件类型是声明，场景是记者会。

### 3.6 六类论元

| 论元 | 含义 | 反例 |
| --- | --- | --- |
| 施事 | 发起或执行该事件 | 「出席会谈」不是施事 |
| 受事 | 被打击、被控制、被波及 | 「旁观」不是受事 |
| 到场 | 出席、参加，但不是施事 | 「主持会议」是施事不是到场 |
| 使用 | 事件中动用的装备 | 装备被摧毁不是使用 |
| 涉及 | 事件关联的文书 | 口头承诺不是作品 |
| 表态 | 谁就此事表态，带 stance 枚举 | 转述第三方观点不算本人的表态 |

表态的 stance 取值：支持、反对、谴责、警告、否认、承认、呼吁、要求、关切、中立。原文没有明确态度词时不建这条边。

### 3.7 复合事件

复合事件是对同篇多个原子事件的概括，10 至 40 字，至少覆盖 2 个原子事件。

判定要点：

- 是概括而非重述其中一个原子事件
- 覆盖的原子事件编号必须正确
- 原子事件不足 2 个时由标题兜底生成，标 `fallback=true`

## 四、RE 卷

### 4.1 十种结构关系

| 关系 | 方向 | 判据 | 正例 |
| --- | --- | --- | --- |
| 隶属 | 机构 → 机构 | 上级机关 | 五角大楼 —隶属→ 美国国防部 |
| 辖属 | 机构 → 机构 | 国别归属，终点是国家 | 韩国国防部 —辖属→ 韩国 |
| 驻地 | 机构 → 地点 | 常驻位置 | 美军中央司令部 —驻地→ 卡塔尔 |
| 部署方 | 装备 → 机构 | 装备由谁部署 | 爱国者系统 —部署方→ 美军 |
| 去向 | 装备 → 地点 | 装备实际移动到某地 | 林肯号 —去向→ 中东 |
| 任职 | 人物 → 机构 | 原文写明职务与机构的对应 | 赫格塞思 —任职→ 美国国防部 |
| 会晤 | 人物 → 人物 | 面对面或通话 | 特朗普 —会晤→ 塞西 |
| 搭载 | 装备 → 装备 | 载体与载荷 | 台风战机 —搭载→ 流星导弹 |
| 位于 | 地点 → 地点 | 行政或地理包含 | 塔伊兹省 —位于→ 也门 |
| 敌对 | 机构 → 机构 | 交火、宣战、明确对抗 | 以军 —敌对→ 哈马斯 |

### 4.2 边界

**任职与隶属。** 任职两端是人物与机构；隶属两端都是机构。「曾在该机构工作」不算任职，必须有明确职务。

**会晤与到场。** 会晤是人物之间的稳定关系，不依赖单次事件；「出席某会议」是事件的到场论元，不进 RE。

**搭载与使用。** 搭载是装备之间的装载关系；「事件使用某装备」是事件的论元。

**位于与驻地。** 位于两端都是地点，是行政或地理关系；部队在某地是驻地。

**敌对与表态。** 敌对要求有具体的对抗事实（交火、宣战）；仅有口头交锋归表态的 stance。

### 4.3 判定动作

对每条候选三元组做四选一：

- **保留**：两端与关系都对
- **改关系**：两端对但关系错，改成正确关系
- **改端点**：关系对但某一端片段错，改成正确片段
- **删除**：原文不支持该关系

另需补充模型漏掉的三元组。只在原文明确写出关系时补，不做推理。

## 五、质量要求

### 5.1 双人独立标注

开发卷与测试卷全部双标，标注员互不通气。

### 5.2 一致性门槛

| 任务 | 指标 | 门槛 |
| --- | --- | ---: |
| NER | 实体片段与类型的 Cohen κ | ≥ 0.75 |
| EE | 事件边界 κ | ≥ 0.65 |
| EE | 事件类型 κ | ≥ 0.75 |
| EE | 话语种类 κ | ≥ 0.75 |
| EE | 论元角色 κ | ≥ 0.70 |
| RE | 三元组 κ | ≥ 0.70 |

事件边界门槛设得低一些，因为涉及片段切分，天然分歧大。

### 5.3 仲裁

两人不一致的交第三人。同一类争议在试点卷累计超过 5 例时，修订本规范并回溯已标部分。

### 5.4 冻结

测试卷标注完成并仲裁后冻结，冻结时记录规范版本号。冻结后不再修改。

## 六、评测指标

### 6.1 NER

微平均 P/R/F1。一条预测正确须片段起止与类型同时匹配。五类各报一个，另报合计。

### 6.2 EE

沿用 CMNEE 口径：

- **Trg-F1**：trigger 片段与事件类型同时正确
- **Arg-F1**：论元角色与片段同时正确

复合事件单独报 F1，`包含` 边的覆盖率作为辅助指标。

### 6.3 RE

三元组全匹配，与 DuIE 一致。只统计有结构关系的实体对，负例按 1:3 采样。

### 6.4 三任务不合并

三个指标分开报，不合成单一总分。实体 F1 不含事件，事件指标不含实体，关系指标不含论元。

## 七、已知限制

**RE 卷规模偏小。** 现有语料以事件报道为主，人物履历与装备编成类信息少。100 篇里只有 29 篇有结构关系，52 条三元组。扩大 RE 卷需要专门筛选含任职、会晤、敌对、搭载、位于语义的稿件，或引入外部语料。

**新增五种关系样本稀少。** 在 100 篇上试抽，任职 7 条、敌对 5 条、位于 5 条，会晤与搭载未出现。评测时需按关系种类分别报，不只看总体。

**零事件篇。** 约 9% 的稿件抽不出原子事件，只能靠复合事件兜底。这类篇目在 EE 卷里仍有复合事件可标，不算空卷。
