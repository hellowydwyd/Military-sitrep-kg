## 8. 已定：时间总体设计（日历 + 叙述顺序 + 重抽对照）

### 8.0 对照怎么拆

| 组 | 抽取 | 写图 | 测什么 |

prompt 已有摘录 / `kind` / `raw_time` 原文。为 TLINK 补一句：**「随后/之后/接着」连接的两个动作必须抽成两条**，分别保留线索词；不要并进「一句一事」。表态用 `kind` 过滤。

### 8.1 两层模型

```text
层 A  日历   Event.event_time + time_precision + 可选 event_time_end
层 B  顺序   Event —TLINK{BEFORE|AFTER|SAME_DAY}→ Event（或 Document 见报）
查询         daily 只用 A；timeline 用 A 排序，缺日历时用 B 在同 doc 内拓扑
```

先后 ≠ 因果。`导致`/`引发` 只留在 `OPEN_REL` 主张，不升格为事件边。

### 8.2 层 A：日历

字段：`event_time` 为 `YYYY-MM-DD` / `YYYY-MM` / `YYYY` / 空；`time_precision` ∈ `{day, week, month, year, interval, fuzzy, unknown}`；`time_background`。**取消 `precision=pub` 与三元组日期回填。**

窗口比较必须按精度分支（月 `YYYY-MM` 与日 `YYYY-MM-DD` 禁止裸字符串比大小）。

解析顺序：绝对日 → 区间（起点/终点分存，`interval`）→ `上周`（发稿−7，`week`）→ `昨天/前天` → `19日`（锚发稿月）→ `今日/今天`（**见报日，`day`**）→ `当天/同日/当天早些时候`（继承同块上一条绝对日，或线索词之前最近的绝对日，写 `SAME_DAY`；没有锚点才 unknown）→ `今年N月`（`YYYY-MM`，`month`）→ `日前/近日`（`fuzzy` + 层 B `BEFORE` 见报）→ `随后/之后/接着/然后`（**同样继承当天日历**，写 `AFTER`；无锚点才 unknown，**禁止用见报日硬填**）→ 其余 `unknown`。`年底` → `YYYY-12` 或 `YYYY`，不写 `12-31`。

早于发稿 ≥30 天：`time_background`（本轮不做「持续状态」例外）。

### 8.3 层 B：同块 TLINK

只连 **同一 chunk** 内、线索词能对上的两事件。属性：`type`、`cue`（原文子串）、`scope=chunk`。无线索不连（禁止按抽取顺序全连 AFTER）。

| 线索 | 边 | 右端锚点 |
|------|-----|----------|
| 随后、之后、接着、然后 | `AFTER` | 同块叙述上一条事件 |
| 当天、同日 | `SAME_DAY` | 同块上一条 |
| 此前、之前、早前 | `BEFORE` | 同块后一条或见报 |
| 日前、近日 | `BEFORE` | Document 见报 |
| 「X后」 | `AFTER` | 句内前一事件 |

跨块、跨文档不连。跨源串线留给以后的 `NEXT_IN_TIME`（共享 canonical × 日历近），与 TLINK 不是一类边。

### 8.4 查询

- `reason.daily`：`precision=day` 且非 background 且 `event_time==该日`。区间不进当日（故意）。空 raw 的 unknown 不进。
- `reason.timeline`：收 `day|week|interval`；`unknown|fuzzy` 进「日期不清」，但同篇内若有 TLINK 则按拓扑排在相关卡片下，标 `cue`，禁止写成「导致」。
- Time-CoT 证据包与 daily 同一过滤；简报校验继续禁「已确认」。
